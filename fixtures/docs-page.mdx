# Install the CLI

{/* Keep the version in sync with the release notes. */}

The command line tool opens files and watches folders. You need version {version} or later.

<Tabs groupId="os">
  <TabItem value="mac" label="Homebrew">

  Run `brew install dotpen`, then open a plan:

  ```bash
  dotpen plan.md
  ```

  </TabItem>
  <TabItem value="manual" label="From Settings">

  Choose **Settings > General > Install Command**.

  </TabItem>
</Tabs>

<Callout type="warning">

The command needs **dotPen 0.1.0** or later. Older builds ignore folders.

</Callout>
